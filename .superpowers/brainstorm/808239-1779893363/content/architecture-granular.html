How the App Composes Them

app-biashara pubspec.yaml dependencies
# The app picks only the packages it needs:

dependencies:
  antinvestor_ui_core: ^0.4.0

  # Manufacturing (the yoghurt-specific ones)
  antinvestor_ui_recipes: ^0.1.0
  antinvestor_ui_production: ^0.1.0
  antinvestor_ui_inventory: ^0.1.0
  antinvestor_ui_equipment: ^0.1.0       # optional
  antinvestor_ui_shelflife: ^0.1.0

  # Commerce
  antinvestor_ui_catalog: ^0.1.0
  antinvestor_ui_orders: ^0.1.0
  antinvestor_ui_customers: ^0.1.0
  antinvestor_ui_procurement: ^0.1.0
  antinvestor_ui_pricing: ^0.1.0

  # Skip these for MVP — add later
  # antinvestor_ui_coldchain
  # antinvestor_ui_quality
  # antinvestor_ui_waste
  # antinvestor_ui_costing
  # antinvestor_ui_demand
  # antinvestor_ui_traceability

A bakery app would use the same packages but skip equipment/coldchain. A cosmetics factory app might add quality/traceability but skip demand. Each app composes only what it needs.
